# Comece aqui

Portfolio pessoal de Lucas Santos para clientes e recrutadores. O conceito é **arquivo digital em movimento**: estrutura clara com linguagem pós-digital, material e humana.

## Roteamento por tarefa

Leia apenas o necessário:

| Tarefa | Fonte |
|---|---|
| Posicionamento, público ou oferta | `planejamento/01 — Direção criativa/` |
| Uso de referências | `planejamento/02 — Matriz de referências/` |
| Cor, tipo, imagem, textura ou composição | `planejamento/03 — Linguagem visual/` |
| Animação, scroll ou adaptação | `planejamento/04 — Linguagem de movimento/` |
| Seções, conteúdo ou percursos | `planejamento/05 — Estrutura e conteúdo/` |
| Revisão de resultado genérico | `planejamento/06 — Anti-padrões/` |
| Aprovação e QA | `planejamento/07 — Critérios de aprovação/` |
| Stack, build ou deploy | `BASE-TECNICA.md` |
| Abertura e ponte | `especificacoes/abertura.md` |
| Selected Work | `especificacoes/selected-work.md` |

Use `DECISOES-ATIVAS.md` para decisões vigentes e `WORKFLOW-IA.md` para implementação e validação. Auditorias são evidências históricas e só devem ser abertas quando citadas por uma tarefa.
