# Portfolio v2 — Lucas Santos

Portfólio pessoal e profissional construído como um **arquivo digital em movimento**.

## Desenvolvimento

```bash
npm run dev
npm run check
```

- `app/`: rotas e estilos globais.
- `components/portfolio/`: experiência principal.
- `components/experiments/` e `experiments/`: protótipos isolados.
- `public/media/`: assets usados pelo produto.
- `assets/`: fontes e derivados do pipeline; cópias em `public/` são saídas de runtime.
- `docs/START-HERE.md`: roteamento da documentação.

O portfólio antigo em `../Portfolio` e snapshots em `references/` são somente leitura.
