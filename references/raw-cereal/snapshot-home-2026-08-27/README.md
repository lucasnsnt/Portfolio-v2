# Snapshot da homepage — 2026-08-27

Origem: https://www.rawcereal.com/

## Conteúdo

- `original/home.html`: HTML integral recebido na captura.
- `original/css/`: stylesheet público referenciado pela página.
- `original/js/`: bundles e bibliotecas públicas referenciados pela página.
- `extracted/home-opening-fragment.html`: recorte mecânico da abertura até o início da próxima seção.
- `extracted/inline-styles.css`: blocos `<style>` reunidos para consulta.
- `extracted/inline-scripts/`: scripts inline separados por ordem de aparição.
- `extracted/asset-urls.txt`: inventário de URLs, sem espelhar imagens ou vídeos.
- `manifest.json`: procedência, tamanho e SHA-256 de cada arquivo original salvo.

## Limites

Este diretório não é uma cópia executável do site e não deve ser transformado em uma. Recursos de mídia não foram baixados. O conteúdo pertence aos respectivos autores e é mantido apenas como referência técnica de leitura.

`original/js/google-tag-loader.js` foi preservado para a captura registrar todo script diretamente referenciado, mas é código de analytics e não possui valor para a adaptação visual.

Para trabalhar no Portfolio v2, consulte primeiro `docs/auditorias/raw-cereal-home.md` e produza adaptações em `experiments/`.
