# Derivações visuais

Transformações autorais produzidas a partir de fontes documentadas em `curated/` ou `external-sources/`.

- `cutouts/`: silhuetas e recortes com transparência;
- `stickers/`: composições fechadas que podem ser posicionadas como objetos;
- `duotones/`: tratamentos tonais e separações cromáticas;
- `masks/`: mapas de opacidade, recortes e formas para composição;
- `transitions/`: sequências ou imagens destinadas a mudanças de estado.

Uma derivação deve manter um arquivo lateral de mesmo nome em `.json`, registrando fontes, operações realizadas, destino pretendido e estado de aprovação. O primeiro corte planejado é uma silhueta derivada da curadoria pessoal.
