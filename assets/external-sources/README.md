# Fontes externas

Arquivos de internet entram aqui apenas quando possuem procedência e permissão de reutilização verificáveis. Referência estética sem permissão não deve ser baixada como asset de produto.

Categorias:

- `archive/`: gravuras, impressão, documentos e acervos históricos;
- `science/`: astronomia, botânica, anatomia, instrumentos e registros científicos;
- `diagrams/`: mapas, esquemas, tabelas e desenhos técnicos;
- `textures/`: texturas com licença compatível ou produzidas a partir de material aberto.

Cada arquivo precisa de uma entrada em `manifest.json`. CC0 e domínio público são preferenciais. Crédito é preservado mesmo quando não for juridicamente obrigatório.
