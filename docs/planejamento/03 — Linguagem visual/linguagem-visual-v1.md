# Linguagem visual

Princípio: **estrutura precisa por baixo; matéria visual por cima**.

## Cor

| Papel | Base |
|---|---:|
| Fundo | `#100D0A` |
| Superfície | `#1D1711` |
| Profundidade | `#33271C` |
| Bronze | `#806044` |
| Areia | `#B39470` |
| Creme | `#E0C5A0` |
| Marfim | `#F2DFC1` |

Valores são iniciais e devem ser calibrados com fotografias reais. Base escura domina; projetos podem introduzir cores temporárias.

## Tipografia

- Grotesca expressiva: títulos, projetos, navegação e CTA.
- Serifada editorial: humanidade e contraste, com moderação.
- Monoespaçada legível: índices, status, anos e tecnologias.
- Famílias finais dependem de testes em português, inglês, mobile e movimento.

## Imagem e textura

- Grão, retícula, fotocópia, compressão, scanlines, desfoque e falha de registro são matéria localizada, não filtro global.
- Quanto mais importante ou longo o texto, menor a interferência.
- Evitar mockups genéricos; homepage pode usar recortes e movimento, enquanto cases priorizam leitura da interface.
- Fotografia pessoal progride de presença abstrata para retrato reconhecível na seção Sobre.

## Composição e componentes

- Desktop: grade de 12 colunas; mobile: 4.
- Assimetria, escala, cortes e espaço negativo devem responder a uma relação visual clara.
- Preferir cantos retos, linhas, molduras editoriais, grandes mídias e botões tipográficos.
- Evitar cards genéricos, pílulas excessivas, glassmorphism, sombras de dashboard e ícones decorativos.

A camada expressiva nunca pode impedir navegação, contraste, foco, leitura ou fallback sem WebGL.
