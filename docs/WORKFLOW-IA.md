# Fluxo de trabalho

1. Leia as fontes apontadas por `START-HERE.md`.
2. Declare função, referência aplicável, adaptação própria, mobile e fallback.
3. Implemente o menor corte vertical útil; efeitos complexos começam em `experiments/`.
4. Verifique conteúdo e fatos; não preencha pendências por suposição.
5. Execute `npm run check`.
6. Renderize e inspecione desktop, mobile e movimento reduzido.
7. Registre somente decisões duráveis; não transforme `DECISOES-ATIVAS.md` em changelog.

Uma entrega só está concluída com build válido, interação essencial acessível e inspeção visual real.
